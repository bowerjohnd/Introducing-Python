# Introducing-Python

Introducing Python, 2nd Edition, Bill Lubanovic © 2020, O'Reilly Media

I have returned to this book after taking a long break. It is not the best style for me to learn, however, I am dedicated to finishing it. This book was published about 6 years ago (Nov. 2019) and I am encountering deprecations in several examples (i.e. redis, sqlalchemy), but always push through them.

Most of Introducing Python is written in the interpreter. So, where necessary, I put most statements in print() to get the result shown in the book. The file naming convention is my way of being able to reference a topic and be able to locate it in the book at a later time. It is by no means how I really name my scripts, I swear. O.o

As of chapter 19, I have decided to name files correctly and include the book example number in a comment as the first line of the code. I have also started committing each file separately with the commit message being the book example number and the topic the file is associated with. Unfortunatly this will jumble up all the files to be in alphabetical order, however, things will work better with imports and easier to find the subjects in the commit messages.
