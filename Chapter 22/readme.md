## 🧮 Math Modules
Python provides built-in modules to handle precise numerical operations and mathematical constants without external dependencies.

* **Basic Functions & Constants**
  * `floor()` / `ceil()` – Rounding down and up to the nearest integer.
  * `pi` / `e` – Standard mathematical constants.
  * `log()` – Natural and base-specific logarithms.
  * `radians()` / `degrees()` – Easy angular conversions.
* **Arithmetic & Algebraic Functions**
  * `factorial()` – Factorial generation for combinatorics.
  * `pow()` – Efficient power and exponentiation operations.
  * `sqrt()` – Square root calculations.
* **Advanced Number Types**
  * `fractions` – Handling rational numbers without floating-point errors.
  * `decimals` – Fixed-point and floating-point arithmetic for high-precision use cases.
  * `complex numbers` – Built-in support for imaginary numbers (\(a + bj\)).

---

## 🔢 NumPy Arrays
The core framework for data science and scientific computing, optimized for vector and matrix operations.

* **Array Creation**
  * `array()` – Converting standard Python lists into n-dimensional arrays.
  * `arange()` – Generating sequential numerical ranges.
  * `zeros()` / `ones()` – Initializing arrays pre-filled with 0s or 1s.
  * `random.random()` – Generating random floating-point values.
* **Manipulation & Math**
  * `reshape()` – Changing array dimensions without altering its data.
  * `slice` – Extracting specific subsets of data using index ranges.
  * `math` – Element-wise broadcasting of mathematical operations.

---

## 📐 NumPy Linear Algebra
Advanced matrix operations and algebraic solvers built directly into NumPy.

* **Matrix Operations** – Transposition, dot products, and matrix multiplication.
* **Vectorization** – Replacing slow loops with highly optimized C-backed array computations.
* **`numpy.linalg` Module** – Solving linear equations, finding determinants, eigenvalues, and matrix inversions.
